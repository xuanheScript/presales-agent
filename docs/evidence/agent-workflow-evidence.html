Presales Agent Evidence

多 Agent 长链推理：从客户需求到成本报价

系统基于 LangGraph 编排四阶段 Agent 工作流，结合 AI SDK 结构化输出、RAG 历史工时参考和流式进度展示，将非结构化需求转化为可追溯的售前估算报告。

1

需求分析

识别项目类型、业务目标、核心功能、技术栈、非功能性需求和潜在风险。

→
2

功能拆解

拆分模块、识别角色、评估各角色人天，并注入历史验证参考作为 RAG 增强。

→
3

工时评估

按角色汇总工时，结合风险、复杂度、第三方对接和合规要求生成缓冲系数。

→
4

成本计算

基于人天成本、风险缓冲和系统配置计算总成本，并输出人员配置与报价结果。

项目解决的核心痛点

  • 售前需求分析依赖人工经验，耗时且不稳定。
  • 功能拆解和工时估算口径不统一，报价难复盘。
  • 历史项目经验分散，难以复用到新项目估算。
  • 客户需求不完整，需要 AI 主动追问和补齐信息。
